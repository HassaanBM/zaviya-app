# Zaviya Grill - StandAlone static site

Plain HTML, CSS and JavaScript. No npm, no build step, no server code.

- Open `index.html` by double-click to view locally, or upload this folder's contents to any static host.
- All links are relative, so it works at a domain root, in a sub-folder, or on a GitHub Pages project URL (user.github.io/repo/).
- GitHub Pages: put the contents of this folder at the repo root (or in /docs) and enable Pages. `.nojekyll` is included.
- Editing: change the HTML files directly. Shared styling is in `assets/styles.css`, behaviour in `assets/app.js`, business details in `assets/config.js`.
- Note: canonical and Open Graph URLs still point to https://zaviyagrill.com. Search-and-replace that if the final domain differs.
- Dish and category photos are hotlinked from the old site's host.
