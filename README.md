# Zaviya Grill

**Fresh from the grill. Ready to order.**

This is the website for Zaviya Grill, a restaurant in North Austin, Texas. It has 238 pages, a full menu, and a cart.

The cart works in the browser only. It does not take payments.

## Run it on your computer

1. Install Node.js.
2. Install the packages: `npm install`
3. Start the site: `npm run dev`
4. Open `http://localhost:8080`.

## Commands

| Command | Result |
| --- | --- |
| `npm run build` | Makes the `dist/` folder for a web server. |
| `npm run build:preview` | Makes the `preview/` folder for GitHub Pages. |
| `npm test` | Builds the site and runs all tests. |

## Folders

- `src/` holds the source code.
- `preview/` holds the GitHub Pages build.
- `dist/` holds the server build. Git does not track it.
